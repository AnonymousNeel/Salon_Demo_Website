## 🚀 Getting Started

### Quick Deploy (Static Site)

**GitHub Pages:**
1. Create a new repository
2. Upload all files
3. Go to Settings → Pages
4. Select "main" branch → Save
5. Your site is live!

**Or use Netlify/Vercel:**
- Drag & drop the folder
- Done!

---

### Full Django Setup

**Prerequisites:**
- Python 3.9+
- pip


## 🎨 Customization

### Change Colors

Edit `css/styles.css`:
```css
:root {
    --ink: #1f1b16;          /* Primary text */
    --accent: #b88b56;      /* Gold accent */
    --cream: #f9f5ee;       /* Background */
    --sand: #f3ece1;        /* Secondary bg */
}
```

### Change Business Info

Update these in each HTML file:
- Business name, address, phone, email
- Service prices and descriptions
- Staff information
- Operating hours

### Add Your Images

Replace Unsplash URLs with your own:
```html
<img src="images/your-photo.jpg" alt="Description">
```
